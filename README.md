# bank-Time-deposit -  Data Mining Project

## Overview

This dataset is a reduced version of the famous Bank Marketing dataset published in the UCI Machine Learning Repository.

 This task involves a bank dataset that we will use to help the bank identify customers with the potential to purchase term deposits. By contacting these specific individuals for targeted marketing, the bank can reduce costs while simultaneously increasing the efficiency of customer acquisition.
